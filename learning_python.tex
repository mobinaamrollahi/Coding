\begin{itemize}
    \item \textbf{\texttt{Counter(iterable)}} (from \texttt{collections}) maps each element to its frequency and is the go-to tool for frequency counting in interview problems.

    \item \textbf{\texttt{most\_common(n)}} returns the $n$ most frequent \texttt{(element, count)} pairs in descending order (omit $n$ for all), making it ideal for top-$k$ frequency problems.

    \item \textbf{\texttt{"".join([char for char in s if char.isalnum()])}} strips a string to only letters and digits using \texttt{isalnum()}, which returns \texttt{True} for a--z, A--Z, and 0--9.

    \item \textbf{\texttt{char.isnumeric()}} accepts any Unicode numeric character (including fractions and superscripts), while \texttt{isdigit()} is stricter (ASCII digits 0--9 only).

    \item Never call \textbf{\texttt{pop(i)}} inside a loop that increments \texttt{i} forward, as each removal shifts remaining indices; a backward loop such as \texttt{for i in range(k, -1, -1): nums.pop(i)} is safe.

    \item \textbf{\texttt{del nums[i]}} is slightly faster than \textbf{\texttt{nums.pop(i)}} at the same O(n) complexity because \texttt{pop} has the extra overhead of returning the removed value, which can matter in tight loops over large lists.

    \item \textbf{\texttt{list.index(i)}} returns the index of the first occurrence of value \texttt{i} in the list, raising \texttt{ValueError} if it is not found.

    \item \textbf{\texttt{list.count(value)}} returns the number of times \texttt{value} appears in the list.

    \item \textbf{\texttt{math.prod(list)}} (from \texttt{math}) returns the product of all elements in the iterable, returning \texttt{1} for an empty iterable.

\end{itemize}

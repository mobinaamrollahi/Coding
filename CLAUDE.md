# Rules for learning_python.tex

1. **Revisit**: A problem is marked Revisit when it was solved but did not beat 100% runtime and a better solution was seen, meaning it needs to be attempted again; when redone with a 100% beat, move its mark to Done.

2. **Done**: A problem is marked Done when it was solved and beat 100% runtime, so it will not be revisited again.

3. **Itemized points**: Each bullet point in the itemized list must be exactly one sentence.
